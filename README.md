# Acompanhamento Financeiro

- **Acesso pelo navegador:** https://thiagobecheleni50-cyber.github.io/acompanhamento-financeiro/
- **Privacidade:** Todos os dados inseridos ou importados permanecem salvos localmente no navegador (`localStorage`) e nos seus backups `.json`.
